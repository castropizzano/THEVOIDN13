## 6. DICAS IMPORTANTES

### ✓ Responda rápido
- Comentários no Reddit: responder em até 2h
- Issues no GitHub: responder no mesmo dia
- Emails/DMs: responder em até 24h

### ✓ Seja autêntico
- Não faça spam
- Não peça stars diretamente
- Deixe o trabalho falar por si
- Seja humilde e aberto a feedback

### ✓ Engaje a comunidade
- Agradeça contribuições
- Credite colaboradores
- Compartilhe aprendizados
- Documente decisões

### ✓ Mantenha consistência
- Commits regulares
- Updates no changelog
- Releases incrementais
- Comunicação ativa
